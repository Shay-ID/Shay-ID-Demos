# Shay-ID Demos | Learning Experience Studio

A standalone collection of seven original, scroll-based HTML concept courses by Shay Panicker.

## Included
- Seven independent course experiences with distinct colour systems and visual identities.
- Course objectives and intended audience.
- Six content chapters per course, with clear section hierarchy and applied guidance.
- Custom SVG hero artwork and supporting illustrations (three per course).
- Interactive workplace scenario practice with immediate feedback.
- Five-question knowledge check with score and review feedback.
- Responsive layouts, scroll progress indicator, reveal-on-scroll motion, sticky navigation and reduced-motion support.
- Static HTML, CSS, JavaScript and SVG assets. No build step or package installation is required.

## Publish with GitHub Pages
1. Upload the contents of this repository to the root of the `Shay-ID-Demos` repository.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. The site will be available at `https://shay-id.github.io/Shay-ID-Demos/` after deployment.
